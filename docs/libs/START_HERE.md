# Libraries Documentation

This directory contains detailed documentation for the key libraries used in the project.

## Directories

*   **[langchain/](./langchain/START_HERE.md):** Documentation for the LangChain library, used for LLM interaction.
*   **[langgraph/](./langgraph/START_HERE.md):** Documentation for the LangGraph library, used for building stateful, multi-actor applications with LLMs.
*   **[sequelize/](./sequelize/START_HERE.md):** Documentation for the Sequelize library, used as the ORM for database interactions.
*   **[cheerio/](./cheerio/START_HERE.md):** Documentation for the Cheerio library, used for web scraping and HTML parsing.
